# Phrase Bank

上課、跟同學聊天、coffee chat 和面試用得到的英文句子，加上遊戲化的練習。

網站：https://joy3450.github.io/

文法庫收錄英文與法文各 76 個主題，可從主題頁直接進入文法練功房。原始遊戲來自 [HsiaoLiang/phrase-bank](https://github.com/HsiaoLiang/phrase-bank)。

## 功能

**學習路徑（參考 Duolingo 的遊戲機制）**

- 每個章節是一個單元，每 5 句一關，依序解鎖；每個單元結尾有寶箱
- 關卡混合題型：選英文、選中文（會朗讀）、用字塊拼句子、默寫、聽寫、配對；答錯的題會在關卡最後重考
- 生命：5 顆，答錯扣 1 顆，每 20 分鐘恢復 1 顆；可在設定關掉
- 寶石：過關、零失誤、開寶箱、每日任務、升級、成就都會給；商店可買連勝凍結、補滿生命、雙倍經驗（15 分鐘）
- 三種難度，每一關都能選：
  - **一般**：選擇題為主，評分寬鬆
  - **困難**（XP ×1.5）：每題限時、選擇題用相似的干擾選項、拼句多 6 個干擾字、新增「填空」和「找錯字」，只容許一個小錯字
  - **傳奇**（XP ×2、+15 寶石）：全部自己打、限時更短、一字不差、聽力最多播 2 次且不能慢速、最多錯 3 題，沒有重考
- 單元考：單元裡的關卡全過後解鎖，10–12 題混合題型（含長句聽寫），限時、最多錯 3 題；通過才能開寶箱（+30 寶石）
- 等級獎勵：Lv.3／Lv.10 愛心上限各 +1、Lv.4 每日任務變 4 個、Lv.6／Lv.14 商店 9 折／8 折、Lv.8 愛心每 15 分鐘恢復、Lv.12 雙倍經驗 20 分鐘、Lv.16 連勝凍結可存 3 個；Lv.2、5、10、20 解鎖新主題色
- 快答加分：限時題在一半時間內答對 +1 XP
- 每日任務：每天 3 個，完成後領寶箱
- 連勝凍結：漏掉一天時自動用掉，保住連續紀錄
- 錯題複習：答錯的句子會被記下來，可以一鍵複習
- 音效（可關）、過關畫面、連續天數畫面、連擊提示

**句子庫**

- **單字卡**：點卡片翻面，可切換先看中文或英文；方向鍵換卡、空白鍵翻面
- **學習**：自己判斷「記得了 / 還不熟」，連續記得有連擊加成
- **默寫**：看中文，用打字或語音（Chrome / Edge / Safari）回答英文。寬鬆比對：大小寫、標點、縮寫、英美拼法、小錯字不扣分，漏一兩個字仍可能算對，並標出漏掉的字；可用提示（XP 減半），也能按「其實我答對了」
- **測驗**：中翻英四選一，結束後列出答錯的題目
- **配對**：計時把英文和中文配成一對，配錯加 1 秒，會記錄最佳時間
- **遊戲化**：經驗值與等級、每日目標、連續學習天數、22 個成就、每組的銅／銀／金／制霸里程碑
- 左側欄：分類進度、章節導覽、篩選；右側欄：等級、每日目標、本週紀錄、成就
- 搜尋、語氣篩選、收藏、朗讀英文、一鍵複製、自己新增句子、深色模式

收藏、學習進度、經驗值和自己新增的句子都存在瀏覽器的 localStorage。

## 內容

共 2000 條，分四類：日常聊天、Coffee chat / 面試、課堂・簡報・會議、單字。資料在 `app/src/lib/raw.ts`，一行一條：

```ts
["分區", "英文", "中文", "例句（可留空）", "casual | neutral | formal"],
```

新句子一定要加在該分類陣列的**最後面**。ID 是「分類 + 第幾條」，插在中間會讓學習進度和收藏對錯句子。

## 開發

原始碼在 `app/`（React + TypeScript + Tailwind CSS + shadcn/ui）。根目錄的 `index.html` 是打包好的單一檔案，GitHub Pages 直接發佈它。

```bash
cd app
pnpm install
pnpm dev          # 本機開發
pnpm run bundle   # 打包並覆寫根目錄的 index.html
```

改完記得跑 `pnpm run bundle`，再把 `index.html` 一起 commit。
